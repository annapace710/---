# rhythmic-gymnastics-assistant

Веб-приложение для анализа видео упражнений художественной гимнастики и выдачи рекомендаций по коррекции техники (риски с булавами)

## 📁 Структура проекта

- `index.html`, `style.css`, `script.js` — фронтенд (статический сайт)
- `main.py` — бэкенд на FastAPI (загрузка видео, анализ позы через MediaPipe)
- `requirements.txt` — зависимости Python
- `uploads/temp/` — временная директория для загруженных видео

## 🚀 Запуск бэкенда локально

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

API будет доступен по адресу `http://127.0.0.1:8000`.
Интерактивная документация (Swagger UI): `http://127.0.0.1:8000/docs`.

### Загрузка с недопустимым форматом (ошибка валидации)

```bash
curl -X POST http://127.0.0.1:8000/upload \
  -F "video_file=@/path/to/file.txt"
```

Ответ:

```json
{
  "error": "Недопустимый формат файла: .txt. Поддерживаются: .avi, .m4v, .mkv, .mov, .mp4, .webm"
}
```

### Загрузка без файла (ошибка)

```bash
curl -X POST http://127.0.0.1:8000/upload
```

Ответ — ошибка `422 Unprocessable Entity` от FastAPI.

## 🎬 Поддерживаемые форматы

MP4, WebM, M4V, AVI, MOV, MKV. Максимальный размер файла — 50 МБ.

## 📊 Метрики анализа движений

Бэкенд вычисляет следующие метрики на основе позы человека (MediaPipe Pose):

Бэкенд вычисляет следующие метрики на основе позы человека (MediaPipe Pose):

| Метрика | Описание |
|---------|----------|
| `torso_tilt` | Угол наклона корпуса от вертикали (средний, макс., мин.) |
| `wrist_height` | Высота запястий при подбросе (средняя, макс., досягаемость) |
| `trajectory` | Траектория центра масс (путь, размах X/Y) |
| `motion` | Скорость и плавность движения (средняя/макс. скорость, плавность, рывки) |

### Признаки, специфичные для упражнений

Бэкенд дополнительно собирает признаки, которые осмысленны только для конкретных упражнений:

| Признак | Упражнение | Описание |
|---------|------------|----------|
| `knee_angle` | `balance` | Угол в коленном суставе (0–180°). Чем ближе к 180°, тем выпрямленнее опорная нога |
| `leg_opening` | `jump` | Угол раскрытия ног (шпагат) между векторами «таз → левая стопа» и «таз → правая стопа» |
| `hip_height` | `jump`, `risk-buhavy` | Нормализованная высота таза (верхняя точка — прыжок, нижняя — группировка в кувырке) |
| `torso_tilt_signed` | `rotation` | Наклон корпуса от вертикали со знаком (симметрия оси вращения) |
| `ankle_height` | `jump` | Средняя нормализованная высота стоп (оценка высоты отрыва) |
| `ankle_y` | `balance` | Высоты левой/правой лодыжки и их разница (определение опорной ноги: ниже стопа — опорная) |
| `arm_symmetry` | `rotation` | Асимметрия рук: модуль разницы высот запястий (0..1, 0 — идеально симметрично) |
| `rotation_turns` | `rotation` | Число витков в пируэте по углу поворота плечевой линии (3D world landmarks) |

## 🎯 Оценка техники и рекомендации

Помимо метрик, бэкенд формирует блок `feedback` — ядро продукта: детекцию ошибок
и рекомендации по коррекции техники для выбранного упражнения.

Ответ включает:

| Поле | Описание |
|------|----------|
| `overall_score` | Общая оценка техники (0–100). Старт со 100, штраф −25 за критичную ошибку, −10 за замечание |
| `errors` | Список найденных ошибок с severity (`critical` / `warning`) и описанием |
| `recommendations` | Конкретные советы по исправлению каждой ошибки |
| `summary` | Итоговое резюме выполнения |

Правила проверки заданы в словаре `THRESHOLDS` в `main.py`:

| Упражнение | Что проверяется |
|------------|-----------------|
| `risk-buhavy` | Глубина кувырка (макс. наклон корпуса), высота подброса булав, группировка (низкий уровень таза), жёсткость ловли |
| `jump` | Высота прыжка (размах Y центра масс), глубина прогиба назад, раскрытие ног (шпагат), вертикальный отрыв (высота таза), высота отрыва стоп, мягкость приземления |
| `balance` | Раскачивание (размах X центра масс), наклон корпуса, выпрямленность опорной ноги (опорная — та, чья стопа ниже, определяется по высоте лодыжек) |
| `rotation` | Завал оси вращения (средний наклон), смещение центра масс, систематический завал в одну сторону, число витков (3D), симметрия рук, неравномерность вращения |

> ⚠️ Пороговые значения — эвристические и уточняются по мере накопления данных.
